## Before publishing

1. Add your real photo as `images/profile.jpg`.
2. Add your CV as `assets/resume.pdf`.
3. Replace `your-email@example.com` in `index.html` with your email.
4. Replace the GitHub and LinkedIn placeholder URLs with your profiles.
5. Add your project screenshots to `images/projects/`.
6. Replace the project placeholder links with your GitHub/live-demo URLs.
7. Open `index.html` in a browser to test it.

## Contact form

The current form is front-end only. It displays a success message but does not send email.
For real submissions, connect it to a service such as Formspree, EmailJS, Netlify Forms,
or your own backend.

## Run locally

You can simply double-click `index.html`, or open the folder in VS Code and use
the Live Server extension.
